# php-login-system
This repo contains login system in php and it requires a database to work properly.
=== PHP Login System ===

1. Copy the 'login-system' folder to your XAMPP 'htdocs' or Laragon 'www' folder.
2. Start Apache and MySQL in XAMPP/Laragon.
3. Go to http://localhost/phpmyadmin and run the SQL in 'db.sql' to create the database and users table.
4. Open http://localhost/login-system/register.html to register a user.
5. Then go to login.html to log in.
6. You will be redirected to dashboard.php if login is successful.

Enjoy!
